# Random User Generator

A simple Random User Generator built with HTML, CSS, and JavaScript.

This project uses an API to fetch user data and displays a randomly selected user profile when the button is clicked. The profile card shows details like the user's name, age, date of birth, gender, email, phone number, address, and profile picture.

I built this project to practice working with JavaScript APIs, asynchronous programming, DOM manipulation, and updating a webpage dynamically based on fetched data.

## Features

- Generate a random user profile with one click
- Fetch user data from an API
- Dynamically update user information and profile image
- Handle API errors with error handling
- Responsive glass-style user card design

## Built With

- HTML
- CSS
- JavaScript
- Fetch API
- DummyJSON API
